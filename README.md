# Student Services Portal

## Description

The Student Services Portal is a TypeScript-based project for a university student services system. This project focuses on establishing a professional development workflow using TypeScript, Git, GitHub, ESLint, Prettier, feature branches, pull requests, and responsible AI-assisted development.

## Requirements

- Node.js
- npm
- TypeScript
- Git
- GitHub
- ESLint
- Prettier
- Visual Studio Code or another approved code editor

## Installation

Clone the repository and install the project dependencies:

```bash
git clone https://github.com/Lynnield/student-services-portal.git
cd student-services-portal
npm install
```

## Run

Compile the TypeScript project:

```bash
npx tsc
```

Run the compiled JavaScript:

```bash
node src/index.js
```

## Linting

Run ESLint with:

```bash
npm run lint
```

## Formatting

Format the project using Prettier:

```bash
npm run format
```

## Development Workflow

The project follows a feature-based Git workflow:

1. Create or select a GitHub Issue for the feature.
2. Create a feature branch from `main`.
3. Develop and test the feature locally.
4. Run linting and formatting checks.
5. Review the changes using `git status` and `git diff`.
6. Commit changes using a meaningful commit message.
7. Push the feature branch to GitHub.
8. Create a Pull Request.
9. Request and address code review feedback.
10. Merge the Pull Request after approval.

## AI Usage Policy

AI tools may assist with development by providing suggestions, explanations, and possible implementations. AI-generated code must be reviewed and understood before it is used. Any suggested code must be modified when necessary, tested, and verified before being committed to the repository. AI recommendations are not accepted automatically and must be evaluated based on the project's requirements, correctness, security, and maintainability.
